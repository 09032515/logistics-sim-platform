# 物流系统智能仿真决策平台 V2 📦

基于 **Python + SimPy + Streamlit + Plotly** 的物流仓库离散事件仿真平台，
覆盖《物流系统仿真》课程实验1~4 全部要求，共 10 大功能。

## ✨ 功能一览

| # | 功能 | 说明 |
|---|---|---|
| 1 | 🧮 智能计算系统 | 输入目标处理量/时间/利用率，自动算出人车配置 |
| 2 | ▶️ 仿真与可视化 | 单次仿真 + 周转周期/利用率/队列/吞吐 12 张图 |
| 3 | 🔍 瓶颈识别 | 三合一打分自动定位瓶颈环节 |
| 4 | ⚖️ 多方案对比 | 预置5套方案横向对比选优 |
| 5 | 📊 批量仿真 | N次独立仿真 + 均值/标准差/95%置信区间 |
| 6 | 🎚️ 敏感性分析 | 参数扫描找边际收益拐点 + 龙卷风图 |
| 7 | 🌪️ 压力情景测试 | 需求暴涨/设备故障抗压检验 |
| 8 | 💡 决策建议 | SLA/预算/瓶颈 → 带失效边界的中文建议 |
| 9 | 📦 数据导入导出 | 结果Excel/配置JSON/历史CSV |
| 10 | 📄 一键自动报告 | 生成自包含HTML仿真报告 |

## 🚀 快速开始

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 📁 文件结构

```
app.py            网页主程序（10个功能标签页）
sim_core.py       SimPy仿真内核（资源/队列/随机模型/批量仿真）
calculator.py     功能1 智能计算
visualization.py  功能2 全部图表
bottleneck_detect.py 功能3 瓶颈识别
scenario.py       功能4 多方案对比
sensitivity.py    功能6 敏感性分析
stress.py         功能7 压力情景
advisor.py        功能8 决策建议
data_io.py        功能9 导入导出
report.py         功能10 自动报告
requirements.txt  依赖清单
```
